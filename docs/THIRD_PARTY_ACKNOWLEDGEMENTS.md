# Third-Party Acknowledgements

This repository is designed to integrate with replaceable third-party modules.
The release does not vendor their source code or model weights.

Common choices include:

- YOLO-World and Ultralytics for open-vocabulary object detection.
- Grounding DINO for open-vocabulary object grounding.
- Segment Anything and SAM2 for promptable image segmentation.
- SeedFormer, PoinTr, AdaPoinTr, PCN, TopNet, and SnowflakeNet for point-cloud
  completion baselines.
- DGCNN, PointNet, PointNet++, and PointNeXt for point-cloud segmentation.
- Contact-GraspNet, AnyGrasp, GPD, and GPG for 6-DoF or parallel-jaw grasp
  candidate generation.
- Open3D and Trimesh for point-cloud and mesh utilities.
- ROS, MoveIt, OMPL, Gazebo, PyBullet, and MuJoCo for robotics middleware and
  simulation, depending on the deployment.
- Intel RealSense SDK for RGB-D camera access.
- AUBO Robotics SDK and DH Robotics gripper interfaces for the tested hardware
  adapter path.

Please follow each upstream project's license, citation, and model-weight
distribution terms.
